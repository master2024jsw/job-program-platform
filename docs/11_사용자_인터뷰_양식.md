# 사용자 인터뷰 양식 (심사④ 대응)

작성일: 2026-11-04 · 상태: **수집 전**

---

## 중요 — 두 가지를 나눠야 합니다

심사④는 "사용자 사용후기 인터뷰 확보"였고, 전제가 **실무자가 써볼 수 있는 테스트 배포본**입니다.
그런데 배포본이 아직 없습니다.

그래서 **지금 할 수 있는 것과 없는 것을 나눴습니다.**

| | 내용 | 시스템 필요? | 언제 |
|---|---|---|---|
| **A형** | 현행 업무 실태 — 지금 어떻게 일하는가, 무엇이 힘든가 | **불필요** | **지금 바로 가능** |
| **B형** | 시스템 사용 후기 — 써보니 어떤가 | 필요 | 배포본 이후 |

**A형만으로도 논문에 쓸 수 있습니다.** 오히려 3장 「문제 분석」의 근거가 되고,
"현장의 목소리로 문제를 정의했다"는 서술이 가능해집니다.

발표에서는 이렇게 말할 수 있습니다.

> 사용후기 인터뷰는 테스트 배포본이 준비되지 않아 수행하지 못했습니다. 대신 현행 업무
> 실태 인터뷰를 N명에게 수행하여 문제 정의의 근거로 삼았고, 사용후기는 배포 이후
> 후속 과제로 남깁니다.

---

## 1. 연구윤리 — 먼저 할 것

논문에 인터뷰를 쓰려면 아래가 갖춰져야 합니다. **심사에서 물어봅니다.**

- [ ] **구두 또는 서면 동의** — 녹음 여부, 논문 활용 범위를 미리 알리고 동의받기
- [ ] **익명 처리** — 실명·기관명을 쓰지 않고 `A기관 담당자`, `참여자 ①` 식으로
- [ ] **철회 가능 고지** — 언제든 빼달라고 할 수 있음을 알리기
- [ ] **소속 기관 승인** — 필요한 경우(기관 업무 내용을 외부에 공개하므로)

### 동의 문구 (읽어드리면 됩니다)

> 안녕하세요. 저는 ○○대학교 석사과정 정세원입니다.
> 일자리사업 행정업무 자동화를 주제로 논문을 쓰고 있고, 현장에서 실제로 어떻게 일하시는지
> 여쭤보려 합니다.
>
> 말씀해 주신 내용은 **논문에만** 쓰고, **성함과 기관명은 익명으로 처리**합니다.
> 기록을 위해 메모(또는 녹음)를 해도 될까요?
> 중간에 답하기 곤란한 질문은 넘어가셔도 되고, 나중에 빼달라고 하셔도 됩니다.
>
> 20~30분 정도 걸립니다. 시작해도 될까요?

## 2. A형 — 현행 업무 실태 인터뷰 (지금 가능)

**대상:** 일자리사업 서류검토를 실제로 하는 수행기관 담당자
**인원:** **3~5명이면 충분합니다.** (질적 연구에서 소수 심층이 일반적)
**시간:** 20~30분
**방식:** 반구조화 — 아래 질문을 뼈대로 하되, 흥미로운 얘기가 나오면 더 파고드세요

### 기본 정보 (익명 처리)

```
- 식별코드:        A-1
- 기관 유형:       (수행기관 / 위탁기관 / 기타)
- 담당 사업:       (시니어인턴십 / 기타)
- 경력:            (년)
- 연간 처리 건수:  (기업 __개사 / 참여자 __명)
- 인터뷰 일자:
- 방식:            (대면 / 전화 / 온라인)
```

### Q1. 업무 흐름 (5분)

1. 기업 모집부터 지원금 지급까지, 선생님이 하시는 일을 순서대로 말씀해 주시겠어요?
2. 그중 **서류를 직접 확인하는** 단계는 어디어디인가요?
3. 서류 한 건을 검토하는 데 보통 **얼마나** 걸리나요?

> 💡 목적: 논문 3장의 업무흐름을 현장 증언으로 뒷받침

### Q2. 부담 (8분) — **가장 중요**

4. 이 업무에서 **가장 시간이 많이 드는** 일은 무엇인가요?
5. **가장 실수가 나기 쉬운** 지점은 어디인가요? 실제로 놓쳤던 경험이 있나요?
6. 같은 내용을 **여러 서류에서 반복해서** 확인하시나요? 예를 들면요?
7. 서류가 미비할 때 기업에 다시 요청하는 일은 얼마나 자주 있나요?
8. **야근이나 주말 근무**를 하게 되는 시기가 있나요? 왜인가요?

> 💡 목적: "왜 자동화가 필요한가"의 근거. **구체적인 숫자와 사례**를 받아내세요.
> "오래 걸려요"보다 "한 건에 40분, 마감 주에는 하루 20건"이 훨씬 강합니다.

### Q3. 암묵지 (5분) — **심사③과 연결**

9. 지침에는 없는데 **실무에서 따로 챙기는** 것이 있나요?
10. 새 담당자가 오면 **꼭 알려줘야 하는** 것은 무엇인가요?
11. 서류는 멀쩡한데 **"이건 좀 이상하다"** 싶었던 경우가 있나요?

> 💡 목적: [10_예외사항_암묵지_수집.md](10_예외사항_암묵지_수집.md)에 바로 들어갑니다.
> **다른 기관 담당자의 암묵지**는 선생님 혼자 적는 것보다 설득력이 큽니다.

### Q4. 자동화에 대한 생각 (7분)

12. 이 업무에서 **컴퓨터가 대신해 줬으면** 하는 부분은?
13. 반대로 **사람이 꼭 봐야 한다**고 생각하는 부분은? 왜인가요?
14. AI가 서류를 읽고 "이 서류는 문제없음"이라고 판정한다면, 그대로 믿고 넘어가시겠어요?
15. (14에서 "아니오"면) **어떻게 보여주면** 믿고 쓰실 수 있을까요?

> 💡 목적: 본 연구의 핵심 주장(AI는 추출만, 판정은 규칙엔진, 결정은 사람) 검증.
> 14번에서 "못 믿는다"가 나오면 **설계 근거가 현장에서 확인된 것**입니다. 그대로 인용하세요.

### Q5. 마무리 (2분)

16. 제가 여쭙지 않았는데 말씀하고 싶은 게 있으신가요?
17. 혹시 이 주제로 얘기 나눠볼 만한 다른 분을 소개해 주실 수 있을까요?

## 3. B형 — 시스템 사용 후기 (배포본 이후)

> 테스트 배포본이 준비된 뒤에 사용합니다. 지금은 **양식만 준비**해 둡니다.

**방식:** 30분 체험 → 인터뷰 20분

### 체험 과제 (관찰하며 기록)

| # | 과제 | 성공 | 소요 | 막힌 지점 |
|---|---|---|---|---|
| 1 | 근로자 서류 7종을 올리고 분석하기 | | | |
| 2 | 분석 결과에서 문제가 있는 항목 찾기 | | | |
| 3 | 그 문제를 해결하기 위해 뭘 해야 하는지 말하기 | | | |
| 4 | 검증 승인하기 | | | |
| 5 | 지원금 안내 대상인지 확인하기 | | | |

> 💡 3번이 핵심입니다. **「다음에 하실 일」이 실제로 통하는지**를 봅니다.
> 설명 없이 혼자 알아내면 성공입니다.

### 정량 문항 (5점 척도)

```
1 전혀 그렇지 않다  2 그렇지 않다  3 보통  4 그렇다  5 매우 그렇다

B1. 화면에서 무엇을 해야 할지 알기 쉬웠다                   1 2 3 4 5
B2. AI가 왜 그렇게 판정했는지 이해할 수 있었다               1 2 3 4 5
B3. 판정 결과를 신뢰할 수 있다고 느꼈다                      1 2 3 4 5
B4. 지금 방식보다 시간이 줄 것 같다                          1 2 3 4 5
B5. 실무에 도입한다면 쓰고 싶다                              1 2 3 4 5
```

### 정성 문항

```
B6.  가장 쓸모 있다고 느낀 기능은?
B7.  가장 불편했던 점은?
B8.  믿기 어려웠던 부분이 있었나요? 어디서 그렇게 느끼셨나요?
B9.  실무에 넣으려면 꼭 추가돼야 할 것은?
B10. 이 시스템이 없는 지금과 비교하면, 한 건당 시간이 어떻게 달라질 것 같나요?
```

## 5. 몇 명이면 되나

- **1~2명**: 사례 소개 수준
- **3~5명**: 논문에 쓸 수 있음 ← **목표**
- 6명 이상: 좋지만 필수 아님

질적 연구는 **적은 수를 깊게** 보는 게 정석입니다. 숫자보다 **구체적 사례와 직접 인용**이 중요합니다.

> **출장 중에도 가능합니다.** 전화·온라인 인터뷰로 하셔도 됩니다.
> A형은 시스템이 필요 없으니 어디서든 할 수 있습니다.

## 6. 논문 어디에 들어가나

| 인터뷰 내용 | 논문 위치 |
|---|---|
| Q1 업무 흐름 | 3장 문제 분석 — 현행 업무 서술 |
| Q2 부담 | 3장 — **연구 필요성의 핵심 근거** |
| Q3 암묵지 | 4장 규칙 체계 + 심사③ 대응 |
| Q4 자동화 태도 | 4장 설계 원칙 검증 (특히 Q14) |
| B형 전체 | 6장 평가 (배포 후) |
| 연구방법 | 1장 또는 3장 — "반구조화 인터뷰 N명" 명시 |
