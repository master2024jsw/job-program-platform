## ApplicationStatus (신청단계 상태)

신청 진행 단계를 한눈에 파악하기 위한 enum. 재직/휴직/퇴사 고용상태와 별개로 관리.

| 값 | 표시 | 설명 |
|---|---|---|
| `UNDER_REVIEW` | 신청검토중 | 서류 접수 후 검토 중 |
| `APPLICATION_COMPLETE` | 신청완료 | 근로자 검증 승인 완료 |
| `SUBSIDY_GUIDANCE` | 지원금안내 | 지원금 신청 안내 단계 |

**자동 전환**: 근로자 검증 승인(`approveWorker`) 시 검증 결과가 `COMPLETE`이면 `APPLICATION_COMPLETE`로 자동 전환

| 파일 | 변경 내용 |
|---|---|
| `packages/shared/src/types/worker.ts` | `ApplicationStatus` enum 및 `Worker.applicationStatus?` 필드 추가 |
| `apps/server/src/modules/workers/worker.entity.ts` | `application_status` 컬럼 추가 (nullable) |
| `apps/server/src/modules/workers/dto/create-worker.dto.ts` | `applicationStatus` DTO 필드 추가 |
| `apps/server/src/modules/workers/workers.service.ts` | 엑셀 내보내기에 "신청단계" 컬럼 추가 |
| `apps/server/src/modules/validation/worker-validation.service.ts` | 승인 시 자동 `APPLICATION_COMPLETE` 전환 |

## 6단계 — 지원금 신청 검증 UI

> 백엔드(`SubsidyValidationService`, `SENIOR-subsidy.json`, 컨트롤러)는 이미 구현 완료 상태였음.
> 이번 작업은 프론트엔드 UI 연결.

### 검증 규칙 목록 (SENIOR-subsidy.json)

**기업 단위 규칙 (companyRules)**

| 규칙 ID | 내용 |
|---|---|
| R-301 | 신청서 사업자번호 = 기업DB 일치 확인 |
| R-301b | 신청서 기업명 기재 확인 |
| R-305 | 가입자명부 취득일 이후 취득 사실 확인 |
| R-308 | 4대보험 취득일·신청서 신청일·공단 신청일 일치 확인 |
| R-309 | 신청서 총 신청금액 ≤ 산출내역서·공단 지급액 확인 |

**근로자 단위 규칙 (workerRules)**

| 규칙 ID | 내용 |
|---|---|
| R-302 | 산출내역 성명·생년월일 = 근로자DB 일치 확인 |
| R-303 | 지원금 산정 검산 (인턴: min(월급여×50%, 40만원) / 채용: min(월급여×50%, 50만원)) |
| R-304 | 채용장려금 신청일 ≥ 근로계약서 인턴 종료일 확인 |
| R-306 | 지급계좌 기업·공단 신청서 일치 확인 |
| R-307 | 이체확인증 이체금액 = 근로자지급 순액 확인 |
